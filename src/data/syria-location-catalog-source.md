# Syria location catalog attribution

`syria-locations.generated.ts` is a compact, app-ready extract of Open-Syria Data Geography **v0.1.5**.

- Source: [Open-Syria/data-geography](https://github.com/Open-Syria/data-geography)
- Dataset overview: [Syrian Cities, Governorates and Localities Data](https://opensyria.org/datasets/geography)
- License: [Creative Commons Attribution 4.0 International](https://github.com/Open-Syria/data-geography/blob/v0.1.5/LICENSE.md)
- Included records: 14 governorates, 62 districts, 272 subdistricts, and 7,605 localities.
- The catalog keeps each record's stable source ID and parent link, with Arabic display names and English fallback names.

The source documents six localities without Arabic names. DALLNI displays their English names until a reviewed Arabic name becomes available. This is reference data, not a complete list of neighborhoods, and location changes should be reviewed before updating the bundled version.
